PRIVACY POLICY

隐私政策

生效日期：2026 年 9 月 9 日

适用范围

本政策适用于个人家庭自动化应用“家庭openclaw”。该应用仅供站点所有者及其家庭使用，不面向公众开放注册。

访问的数据与用途

在用户通过 Google OAuth 明确授权后，应用可能以只读方式访问 Gmail 邮件内容和必要的邮件元数据，仅用于识别、提取和整理与授权用户本人账单、收据及交易通知有关的信息。应用不会代表用户发送、修改或删除邮件。

处理、存储与共享

数据在站点所有者控制的本地设备和私有自动化环境中处理。OAuth 凭据及从 Gmail 提取的数据不公开，不出售，不用于广告、信用评估或训练通用人工智能模型，也不会与第三方共享；法律明确要求或用户主动要求的情形除外。

数据仅在实现家庭自动化功能所需的期限内保留。所有者可随时删除本地数据及凭据。

Google API 数据

家庭openclaw对从 Google API 获取的信息的使用和传输，将遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。

撤销授权与删除数据

用户可随时在 Google 账号的第三方连接页面撤销授权。站点所有者也可直接删除本地保存的 OAuth 凭据及相关提取数据。如需联系，可通过本站公开 GitHub 仓库的 Issues 提交请求。

政策变更

如果数据用途或处理方式发生实质变化，本页面会在变更生效前更新。
